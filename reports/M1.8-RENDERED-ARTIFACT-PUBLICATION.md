# M1.8 rendered Artifact publication

Status: pass for `M1.8-EV06`; `M1.8-W07` and `M1.8-W08` complete

Scope: content-addressed export bytes, private rights, and durable RenderedArtifact lineage

Date: 2026-09-04

## Outcome

Petra can now publish deterministic Markdown, standalone LaTeX, and BibTeX as
verified export Artifacts. Each RenderedArtifact resolves from an exact
DraftArtifact revision and CitationBundle to the exact content hash, byte size,
media type, object-store coordinate, renderer profile, and service Actor that
created the representation.

The PostgreSQL record repeats the no-authority boundary in queryable form: an
export is a representation of scientific content, not new scientific evidence,
and its renderer may not change support.

## Publication sequence

1. Validate the renderer's service, input references, semantic hash, output
   Artifact reference, UTF-8 text, byte size, and byte hash.
2. Reuse exact content-addressed bytes when already available; otherwise stage,
   verify, and make them available through `ArtifactStore`.
3. Register the generated export Artifact, its storage manifest, and its private
   rights decision through the existing PostgreSQL authority boundary.
4. Persist the RenderedArtifact only after PostgreSQL can resolve the exact
   DraftArtifact, CitationBundle, output Artifact, Project, and rendering Actor.

Object storage and PostgreSQL do not pretend to share a transaction. If the
process stops after byte or Artifact publication, an exact retry recognizes the
same identities and completes the missing RenderedArtifact link. It neither
duplicates the export nor assigns an orphan scientific meaning.

## Rights behavior

Generated exports may be stored, parsed, indexed, and embedded locally. Remote
text transmission, public quotation, and redistribution remain disabled by
default. The generated-output decision explicitly states that rights attached
to source materials do not transfer to the representation and directs later
publication workflows back to the cited source manifests.

## Executable evidence

Migration `V016__rendered_artifact_authority.sql` adds exact composite keys for
draft, citation, and output identities; immutable RenderedArtifact rows; a
single deterministic format/profile slot per draft revision; typed lineage;
semantic-hash equality; and database-enforced false authority flags.

A clean PostgreSQL 18.6 database applies and validates all 16 migrations. All 70
real repository cases pass, including three-format publication and byte reads,
exact replay, restart rehydration, private rights, interrupted-publication
recovery, changed-byte refusal, missing-output refusal, identity and slot
conflicts, and direct SQL mutation rejection.

The complete repository gate also passes with 581 always-on tests and seven
expected service-dependent skips.

## Next boundary

The next M1.8 increment opens researcher editing as a new DraftArtifact revision,
preserves edit origin and prior history, marks affected provenance and citations
