# M1.9 Project shell integration

- **Status:** First live M1.9-W04 slice passed
- **Verified:** 2026-09-08
- **Design boundary:** Frozen presentation preserved; data authority replaced
- **Depends on:** [D018 ProjectDefinition foundation](D018-PROJECT-DEFINITION-FOUNDATION.md)

## Result

The production Projects route and shared Project shell no longer import neutral
reference Projects. They read authenticated `PetraProjectShellView` records
from the Hono server, which composes each response from PostgreSQL under one
read-only repeatable-read transaction.

The view binds:

- the current `petra.project@1.0.0` revision;
- the exact current ProjectDefinition revision and its terminology;
- the exact current focused Objective revision, when one is selected;
- global authority event position and Project stream revision;
- the current authority-graph checkpoint and safe represented position; and
- projection-derived attention without treating the graph as authority.

React maps this authorized view into the frozen presentation model. It does not
join Project, definition, Objective, event, or projection records. Definition
terms drive the visible focus, finding, and reference labels; a generic Petra
term is used only when a definition omits that optional semantic family.

## Failure behavior

- API reads require the existing bearer-token boundary.
- A missing Project returns `PROJECT_NOT_FOUND`; the server and client do not
  substitute a reference Project.
- A Project without a current ProjectDefinition fails closed and cannot be
  interpreted by the shell.
- An unavailable read boundary or incoherent stored record returns an explicit
  service failure.
- A missing graph checkpoint leaves Project authority readable and labels the
  projection unavailable.
- Catching-up and blocked projections expose represented and observed event
  positions plus a bounded attention item.

The local browser adapter reads a token from `petra.auth.token` in session
storage and otherwise uses the documented local-development token. A packaged
or nonlocal runtime still needs a server-mediated session bootstrap before this
development fallback can be removed.

## Frozen-design treatment

No design-system CSS, layout, route names, or component visual hierarchy changed
in this slice. Neutral examples remain available to explicit fixture galleries
and component tests. Production `/` and `/projects/:projectId/*` loaders now use
the live query adapter.

Surfaces without an authorized live collection contract remain visibly empty
or unavailable for a live Project. They do not fall back to same-named fixture
records. The source and Review slices are now implemented separately;
relationship-graph, Work, composition, and History views remain subsequent W04
slices.
