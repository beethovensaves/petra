The prompt contract was then corrected to map each final coverage field to its named packet control. Because this changed the prompt hash, it also changed the observable deployment identity and required a fresh run. The corrected deployment passed all three certification cases:

2. one malformed-output negative control; and
3. one escaped-reference negative control.

## Reproduction and invalidation

```sh
npm run test:codex-synthesist:certification
```

`PETRA_CODEX_SYNTHESIST_MODEL` may select another model exposed by the current ChatGPT entitlement. Another model, model revision, Codex runtime, schema projection, prompt hash, packet dataset, scope, or validator set is a different deployment and must earn its own certification.

The command makes one certification observation and, only after an active result, one production-gateway call. Both turns are ephemeral, read-only, tool-disabled, and use managed ChatGPT OAuth.

## Limits

This is a bounded M1 fixture, not evidence that Terra is reliable for every scientific domain or prompt. The suite tests exact schema, provenance, coverage, origin separation, and two deterministic negative controls over one small packet. Broader quality, adversarial, latency, and model-comparison suites remain required before public deployment.
