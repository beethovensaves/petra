# M1.9 backend gate matrix

Status: executable backend matrix complete; cumulative M1 demonstration remains
open

Date: 2026-09-04

## Outcome

`npm run test:m1:backend` now runs Petra's deterministic backend evidence in a
fixed order: repository and cross-runtime checks, real PostgreSQL, real
S3-compatible artifact storage, real Neo4j projection and rebuild, the pinned
offline Docling worker, deterministic proposal quarantine, and cross-system
backup, restore, and graph reconstruction. Each stage names the `M1.9-T*`
groups it exercises and fails the command immediately with the responsible
component name.

`npm run test:m1:backend:list` prints the matrix without running it. A single
stage can be diagnosed with:

```sh
node scripts/test-m1-backend-gates.mjs --stage=postgres
```

The runner does not need an OpenAI API key, does not perform live model calls,
and does not alter a developer's normal Petra services. The individual service
harnesses use isolated Compose project names and verify cleanup.

The first complete run passed on 2026-09-04 in 108 seconds. It included 599
always-on repository tests with seven expected service skips, 80 real
PostgreSQL cases after 18 migrations, nine real ArtifactStore cases, three real
Neo4j/PostgreSQL cases, two stable 116-span Docling parses plus a malformed-PDF
failure, and a fresh proposal run admitting two grounded candidates while
rejecting its fabricated negative control. The Docling and proposal stages
reported zero remote model calls.
