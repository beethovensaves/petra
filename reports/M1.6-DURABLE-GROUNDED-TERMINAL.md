# M1.6 durable grounded terminal

Status: pass

Scope: `M1.6-W20`, `M1.6-AC04`, and `M1.6-AC07`

Date: 2026-09-04

## Outcome

Petra now emits a scientific answer only after its exact grounded terminal has persisted. The terminal binds the validated synthesist execution to immutable Markdown bytes in S3-compatible storage and to revisioned PostgreSQL records for the Artifact, WorkUnit, InteractionRun, packets, and GroundedResponse.

The server-owned Codex route cannot start without this terminal boundary. If any terminal operation fails, the interaction emits `GROUNDED_TERMINAL_PERSISTENCE_FAILED` and no answer text. AG-UI remains a presentation protocol and gains no scientific-authority effect.

## Persist-before-display order

```text
bounded retrieval and packet selection
  → certified model execution or exact durable execution reuse
  → schema, evidence, origin, and provenance validation
  → content-addressed Markdown publication
  → Artifact, manifest, and rights registration
  → WorkUnit revision 1 → 4
  → InteractionRun revision 1 → 2
  → GroundedResponse registration or exact cache reuse
  → persistence-complete activity
  → answer text
  → AG-UI terminal binding
```

The terminal result exposes exact GroundedResponse, Artifact, InteractionRun, and WorkUnit IDs, revisions, and hashes. It also reports whether synthesis came from the provider, the process-local cache, or the durable execution cache.

## Storage and convergence

Response bytes use the exact media type `text/markdown; charset=utf-8`. Their Artifact identity derives from the content hash, so identical bytes converge on one immutable Artifact. Distinct executions can attach separate acquisition manifests without inventing duplicate byte identities.

GroundedResponse invalidation is atomic within PostgreSQL: one relevant authority event either advances every affected response and records its cause or changes nothing. The complete terminal spans PostgreSQL and S3-compatible storage, so it is not presented as a distributed transaction. It is a fail-closed, idempotently convergent sequence. An interrupted attempt may leave valid operational records, but Petra emits no answer; an exact retry reuses those records and completes the same terminal.

## Restart and cost behavior

Before starting a model turn, the synthesist gateway can look up the deterministic ModelRequest in PostgreSQL. It accepts the stored execution only after rechecking the request and call hashes, ordered call set, exact ContextPacket and EvidencePacket bindings, current registered deployment and certification, successful output hash, and packet-grounding validator.

This path preserves scientific and model provenance while avoiding repeat model cost and latency. A cache-served interaction receives its own WorkUnit and InteractionRun, while the immutable GroundedResponse and response Artifact remain shared.
