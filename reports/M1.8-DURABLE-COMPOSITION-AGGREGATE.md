# M1.8 durable composition aggregate

Status: pass for `M1.8-EV04`; `M1.8-W04`–`M1.8-W06` complete

Scope: atomic PostgreSQL persistence and restart recovery for the first scientific draft

Date: 2026-09-04

## Outcome

Petra now commits a DraftArtifact, all of its DraftSpans, its exhaustive
ProvenanceMap, and its CitationBundle as one durable aggregate. A failed
reference or component write rolls back the whole composition; no partially
grounded draft can remain visible.

The repository validates the portable contracts and the in-memory composition
semantics before writing. It then requires the exact durable
CompositionRequest, CompositionPlan, EvidencePacket, canonical citation
records, producer and compiler Actors, and—for a model-produced draft—the one
current reusable GroundedResponse with the same model execution, packet, and
snapshot.

## Durable structure

- DraftArtifact identities have a guarded current-revision pointer and an
  immutable revision ledger prepared for additive editing.
- DraftSpans retain Unicode-code-point offsets, exact text hashes, materiality,
  semantic origin, and scientific force as typed columns and full payloads.
- Provenance mappings and each individual basis remain ordered and queryable;
  evidence bases preserve their exact selected object revision and hash.
- Citation entries preserve canonical Work, WorkVersion, Author, and external
  identifier hashes, bibliography keys, source depth, and linked DraftSpans.
- A normalized authority-dependency ledger closes over directly used evidence,
  supporting SourceSpans, and canonical citation identities. It is indexed for
  later invalidation and graph-projection work.
- Deferred foreign keys represent the intentional cycle in which the draft
  names its provenance and citation records while those records name the exact
  draft revision.

The immutable contract payload remains the recovery representation. Typed and
normalized rows are its constrained query indexes, not an alternative source
of scientific meaning.

## Failure behavior

- Exact retries return the already stored aggregate without duplicating rows.
- A reused DraftArtifact ID with different content fails as an identity
  conflict.
- Reusing any DraftSpan, ProvenanceMap, or CitationBundle identity across
  aggregates fails before insertion.
- Missing or hash-different canonical citation authority fails before the
  aggregate is written.
- A model draft whose exact GroundedResponse is absent or no longer reusable
  fails closed.
- Direct SQL update or deletion of any aggregate component is rejected.
