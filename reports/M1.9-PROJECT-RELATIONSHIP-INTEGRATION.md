# M1.9 Project relationship integration

- **Status:** Fourth live M1.9-W04 slice passed
- **Verified:** 2026-09-08
- **Design boundary:** Frozen Graph presentation preserved; relationship data authority replaced
- **Depends on:** [Project Review integration](M1.9-PROJECT-REVIEW-INTEGRATION.md)

## Result

The production Graph route now consumes an authenticated
`petra.project-relationship-view@1.0.0` record. It no longer selects a
same-named reference graph in React.

The first bounded reader answers one current scientific provenance question:
it selects one Project-scoped trusted `ASSERTS` relationship and returns its
exact WorkVersion, Work, Claim, SourceSpan, and Artifact path. The response
includes the ProjectDefinition terminology, optional focused Objective,
request identity, exact record and relationship revisions, authority and graph
positions, path order, scope, completeness, omissions, limitations, and an
accessible textual peer. It contains no renderer geometry.

Neo4j remains a rebuildable projection. The reader opens a PostgreSQL
repeatable-read transaction, resolves the current authoritative graph
checkpoint and outbox head, verifies Neo4j against that checkpoint before and
after graph reads, and then reproduces every returned node and edge from exact
PostgreSQL records and canonical hashes. SourceSpan text and ProjectSource
destinations come from PostgreSQL authority rather than graph properties.

The workbench maps that contract into the frozen Graph model. Current graph and
text representations use the same exact nodes and relationships. Position is a
deterministic client layout with no scientific meaning. Unsupported working and
historical controls remain visible but unavailable. A missing supported path
uses the existing Graph empty-state composition and does not substitute a
whole-Project network or fixture.

## Deliberate version-one boundary

This slice is current-only and scientifically specialized. It does not claim:

- a whole-Project graph;
- working or historical membership;
- snapshot comparison or temporal reconstruction;
- generic expansion or continuation cursors;
- graph-authored scientific semantics; or
- a recommendation, working branch, Review link, or Work link that authority
  did not supply.

The contract declares those capabilities unavailable. Later profile-specific
resolvers can add other bounded relationship tasks without changing the shared
rule that ProjectDefinition supplies terminology and registered semantics. A
template may seed a definition, but the reader does not assume that a Project
belongs to a template catalogue.

## Authority and failure behavior

- Both endpoints of the selected relationship must belong to the exact Project.
- The selected graph relationship must carry its Assertion identity and resolve
  to the same PostgreSQL Assertion revision and record hash.
- The source-grounded Claim must reproduce the complete projected SourceSpan
  set, and every span must resolve through one exact active or retained excluded
  ProjectSource binding.
- Structural graph edges are accepted only when their hashes reproduce the
  exact authoritative WorkVersion, Claim/source-span membership, and SourceSpan
  location records.
- A projection ahead of authority, a checkpoint mismatch, substituted Project,
  missing exact record, corrupt hash, incomplete provenance path, unregistered
  Claim/Assertion semantics, or unsupported non-text peer fails explicitly.
- A catching-up or blocked projection may expose its last coherent represented
  position with the newer authoritative position and pending count disclosed.
- No checkpoint or supported current `ASSERTS` path returns not-found. The
  browser shows an honest empty state. An unconfigured or failed read boundary
  returns an explicit unavailable error.

## Frozen-design treatment

reference fixtures remain available only to fixture galleries and component
tests. The production route uses its server loader. Existing graph selection,
local back/forward history, layout toggle, source return path, and graph/text
peer remain client-owned view state.
