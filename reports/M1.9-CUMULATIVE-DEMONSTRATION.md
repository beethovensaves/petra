# M1.9 cumulative demonstration

Status: M1.9-W03 complete; M1.9-W04 remains open

Date: 2026-09-08

## Outcome

The command npm run test:m1:cumulative runs M1.9-DEMO-01 through
M1.9-DEMO-15 as one clean-start trace. The verified run passed all fifteen
steps and removed every Compose container, network, and volume created for the
test.

The trace carries one FAIR Principles source through Project and scholarly
identity, verified bytes and rights, the pinned offline Docling worker,
SourceSpan inspection, proposal quarantine, review promotion, Neo4j
projection, graph-guided retrieval, bounded packets, grounded composition,
non-destructive reversal, invalidation, replay, rebuild, AG-UI review,
reconnect, delivery abort, and explicit cancellation.

The checked-in result is
[M1.9-CUMULATIVE-RESULT.json](M1.9-CUMULATIVE-RESULT.json). Each local run also
writes .data/m1.9/cumulative-result.json after successful cleanup.

## Reproduction

The command requires the repository's pinned Node 24.20.0 runtime, verified
local Docling models, and a running Docker daemon:

    npm run test:m1:cumulative

The harness verifies the package build and Docling model inventory before it
starts a uniquely named disposable PostgreSQL 18.6, SeaweedFS 4.41, and Neo4j
2026.07.1 stack. It applies all migrations to a new database. Any failure is
reported with the active setup component or M1.9-DEMO identifier. Cleanup runs
unconditionally, and the pass manifest is written only after the harness
confirms that no labeled Docker resources remain.

## Recorded result

The passing run retained:

- one Project, Work, WorkVersion, source Artifact, parser Artifact, and
  ParsedDocument identity chain;
- 116 structural blocks and 116 SourceSpans from the real PDF;
- two admitted proposals and one rejected negative control, with no remote
  model call;
- nine lifecycle and authority events, three Neo4j outboxes, and a current
  final projection checkpoint;
- all three revisions of the reversed primary Claim, whose current state is
  quarantine, and the accepted qualification at trusted revision two;
- three selected EvidencePacket objects, two material DraftSpans, one canonical
  citation, and three rendered formats;
- an idempotently resolved review interrupt, a completed run with one aborted
  delivery, and a separately cancelled run.

PostgreSQL remains scientific authority, the ArtifactStore remains byte
authority, and Neo4j remains a rebuildable projection. Interaction state does
not become scientific authority.

## Design-freeze boundary

This evidence closes M1.9-W03 against the accepted backend contracts. It does
not claim that the frozen neutral workbench is live, that fixture-backed
reference screens are integrated, or that the broader UX request set is
complete. M1.9-W04 remains the interface integration and recovery-assertion
gate.

The extraction and composition in this harness are deterministic. They prove
contract composition, identity, provenance, authority, invalidation, and
protocol behavior; they are not evidence of live-model quality. Component
certification and full repository gates remain recorded separately in the
backend matrix.
